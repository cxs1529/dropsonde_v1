Field Terminology Guide

Planned Deployment: This is the goal location for where we want to put the dropsonde in the water for the cast.

Approximate Recovery: This is where we expect the dropsonde will surface again, within a few hundred yards. Note this ASSUMES THE DROPSONDE WAS DEPLOYED AT THE PLANNED SITE! Otherwise, use this as a guide for how far the dropsonde should have moved from the actual deployment site.

Approximate length of time: This is an estimate for how long the dropsonde should be under water during each cast. This number may vary by a few minutes.
